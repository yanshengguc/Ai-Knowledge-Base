# 业务线三:评估与质量线

> 内容口径与 `docs/PROJECT-EVIDENCE.md` 一致,所有数字可复现。

## 定位

"它答得像对的"≠"它答的是对的"。这条线回答:**怎么证明系统质量存在、且没有在悄悄变差**。三层防线:自动化测试(正确性)→ 评估集(模型行为)→ 攻防与变异测试(安全与测试有效性)。

## 第一层:测试分层(50 文件 / 184 用例)

| 组 | 规模 | 依赖 | 跑法 |
|---|---|---|---|
| 默认回归 | 152 用例 | 无外部依赖 | `mvn test`(CI 友好) |
| integration | 9 文件 / 21 用例 | 真实 MySQL + Redis + DashVector | `-Dgroups=integration -DexcludedGroups=e2e` |
| e2e | 8 文件 / 11 用例 | 真实 LLM/向量库(少量费用) | `scripts/test-e2e.sh` |

**已知取舍**:后两组默认跳过(需外部服务与真实模型),它们恰恰是唯一能回答"质量有没有下降"的测试——本地必须定期完整跑。铁律:**任何代码改动全量回归绿才可提交部署**。

## 第二层:模型行为评估(不是"感觉良好")

| 评估 | 数据集 | 指标 | 结果 |
|---|---|---|---|
| 检索质量(`RetrievalQualityEvalTest`) | 18 查询 / 12 篇文档(JSON 配置,加用例不动代码) | recall@5 / MRR,回归阈值 0.80 / 0.70 | 达标;真实管线注入非 mock |
| 工具选择(`EvalHarnessTest`) | 15 个"该调/不该调"用例 | 选择准确率 | 15/15(测试集结果,真实场景持续迭代) |

设计要点:**golden set 是 JSON 不是代码**——调切片/embedding/重排参数后重跑,指标不达标就拦,这就是 `ctx-guard` 思路在 Java 侧的雏形。

## 第三层 a:安全攻防(24 项,退出码=漏洞数)

`scripts/security_attack.py`:攻击者视角(注册受害者 A + 攻击者 B,B 拿**合法 token** 打 A 的资源),输出逐条 [SAFE]/[VULN],可进 CI 回归。

- 第一轮手工 15 项发现 3 个 bug;第二轮脚本化后又发现 6 个漏洞——**含两个可拖库的文件 IDOR**(B 的 token 直接读 A 的文件详情/清单)
- 6 漏洞全部修复并**生产复测**(重放攻击确认拦截),完整记录见 EVIDENCE 第六节
- 附带加固:file_trace 内部走 getFileById → 自动继承作者校验(工具层纵深)

## 第三层 b:变异测试(防"假测试")

测试多不等于质量高——"接口 200 就算过"的假测试比没有测试更危险。方法:**故意注入真实错误,对应测试必须爆红**。

| 注入错误 | 模拟事故 | 测试反应 |
|---|---|---|
| 计费基数 1_000_000→100_000 | 成本账本虚报 10 倍 | TokenCostCalculationTest 红 ✅ |
| 删除越权校验反转 | 任何人可删他人知识 | KnowledgeDeleteCascadeTest 红 ✅ |
| 白名单放行 .exe | 恶意文件进 OSS | FileUploadBoundaryTest 红 ✅ |
| 登录锁定阈值 5→5000 | 无限撞库 | LoginLockoutBoundaryTest 红 ✅ |
| 限流 off-by-one | 第 10 次误拒 | RateLimitBoundaryTest 红 ✅ |

5/5 全红 = 测试体系有效;同批揪出 9 个零断言假测试删除(它们每轮回归还烧真实 LLM 费用)。

## 边界审视文化

比报错更危险的是**静默失败**:扫描版 PDF 曾会被静默标成功但永远检索不到——修复为显式 FAILED + 原因落库可读。另一个教训:换 embedding 模型不重建 collection,长期记忆静默失效(降级逻辑掩盖故障)——**降级必须配可观测性**,健康检查与维度校验在路线图上。

## 容错清单(故障演练口径)

```
① Redis 挂 → 会话降级查 MySQL   ② 联网搜索挂 → 降级纯知识库
③ 上传失败 → 状态机 FAILED+原因  ④ 死循环 → max_steps=5
⑤ 工具失败 → 错误回传自愈        ⑥ 限流 → INCR 每用户 10 次/分
⑦ 越权 → 归属校验               ⑧ 探活 → /actuator/health
```
